# Minecraft Mods

## Flushable Toilet

A Fabric mod that adds a toilet you can flush. Right-click to flush; items dropped in the bowl get flushed away.

| Folder | Minecraft version |
| --- | --- |
| [`flushabletoilet-26.3`](flushabletoilet-26.3) | **26.3** (latest) |
| [`flushabletoilet-1.21.8`](flushabletoilet-1.21.8) | 1.21.8 |
| [`FlushableToilet-Installer`](FlushableToilet-Installer) | PowerShell installer for 26.3 |

**Download:** [FlushableToilet-Installer-26.3.zip](FlushableToilet-Installer-26.3.zip) (latest) or [FlushableToilet-Installer-1.21.8.zip](FlushableToilet-Installer-1.21.8.zip). On the file page, click the download button.
